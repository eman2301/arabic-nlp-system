# Arabic NLP System

An end-to-end Natural Language Processing project for Modern Standard Arabic using the AAFAQ question-answering dataset.

The system combines three NLP tasks:

- **Question Answering** using RNN, GRU, LSTM, mT5, AraGPT2, and Qwen2.5
- **Text Classification** using Gaussian Naive Bayes, Linear SVM, and fine-tuned AraBERT
- **Arabic-to-English Machine Translation** using GPT-4o-mini through the OpenRouter API

A Streamlit application integrates the selected models into a single interactive system that generates Arabic answers, predicts question categories, and provides English translations.

## Dataset

This project uses the **AAFAQ Arabic Question Answering Dataset**, containing **5,009 Modern Standard Arabic question-answer pairs** across **17 categories**.

The dataset includes:

- `QuestionText` – the Arabic question
- `Category` – the question category
- `Answer` – the corresponding Arabic answer

Both the original and preprocessed datasets are available in the `data/` directory.

## Preprocessing

The Arabic text preprocessing pipeline includes:

- Removing emojis, diacritics (Tashkeel), and Tatweel
- Normalizing Arabic characters
- Removing punctuation, symbols, and numbers
- Removing extra spaces
- Stopword removal
- Tokenization
- Stemming using ISRI and Snowball stemmers
- Lemmatization using Qalsadi

Different preprocessing approaches were compared to select methods that balance efficiency and preservation of Arabic meaning.

## Question Answering

Several neural and transformer-based models were evaluated for Arabic question answering, including:

- RNN
- GRU
- LSTM
- mT5
- AraGPT2
- Qwen2.5

Different text representations were also explored, including TF-IDF, AraVec CBOW, and AraBERT embeddings.

The transformer models achieved the strongest results. **Qwen2.5 was selected as the final question-answering model** because it achieved the highest COMET score, indicating the strongest semantic quality.

| Model | BLEU | COMET |
|---|---:|---:|
| mT5 | 16.07 | 0.554 |
| AraGPT2 | 5.21 | 0.500 |
| Qwen2.5 | 13.80 | **0.780** |

## Text Classification

Multiple machine learning and transformer-based approaches were evaluated for classifying AAFAQ questions into **17 categories**.

The experiments included:

- Gaussian Naive Bayes
- Linear SVM
- TF-IDF and Bag-of-Words features
- AraVec CBOW and Skip-gram embeddings
- AraBERT embeddings
- Fine-tuned AraBERT

The **fine-tuned AraBERT model** achieved the best overall classification performance and was selected for the final system.

| Model | Accuracy | F1-Score |
|---|---:|---:|
| Gaussian NB + AraBERT Embeddings | 66.97% | 67.12% |
| SVM + AraBERT Embeddings | 78.44% | 78.50% |
| Fine-Tuned AraBERT | **85.93%** | **85.93%** |

## Machine Translation

Arabic-to-English machine translation was implemented using **GPT-4o-mini through the OpenRouter API**.

The translation component takes Arabic text from the system and generates an English version of the output.

The API key is loaded securely using the environment variable:

`OPENROUTER_API_KEY`

This prevents sensitive credentials from being hard-coded in the source code.

## Streamlit Application

A Streamlit interface integrates the three NLP components into one application.

The application allows users to:

- Enter an Arabic question
- Generate an Arabic answer using the fine-tuned Qwen2.5 model
- Predict the question category using the fine-tuned AraBERT classifier
- Translate the generated Arabic answer into English

The application code is available in:

`app/app.py`

## Model Checkpoints

The trained model checkpoints are not included in this repository because of their large file sizes.

The notebooks contain the training and export workflow for generating the required models.

The Streamlit application requires the following trained model files:

- `best_qa_qwen_merged/` – fine-tuned Qwen2.5 question-answering model
- `best_classification_bert/` – fine-tuned AraBERT classification model
- `label_encoder.pkl` – classification label encoder

These files can be generated by running the corresponding question-answering and classification notebooks.

## Installation and Setup

Clone the repository:

```bash
git clone https://github.com/eman2301/arabic-nlp-system.git
cd arabic-nlp-system
```

Install the required Python packages:

```bash
pip install -r requirements.txt
```

Set your OpenRouter API key as an environment variable before running the application.

For Windows PowerShell:

```powershell
$env:OPENROUTER_API_KEY="your_api_key_here"
```

For macOS or Linux:

```bash
export OPENROUTER_API_KEY="your_api_key_here"
```

Replace `your_api_key_here` with your own OpenRouter API key.

**Never upload or commit a real API key to GitHub.**

## Running the Application

Make sure the required trained model checkpoints have been generated using the question-answering and classification notebooks.

Then run the Streamlit application from the project root:

```bash
streamlit run app/app.py
```

Streamlit will open the Arabic NLP application in your browser.
